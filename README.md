# Forge Arena

A browser fighting game. Build a fighter from a **Top**, **Middle** and **Bottom** section, then battle in a 3rd-person arena.

- Each section has Light, Middle and Heavy parts (3 of each, 729 combinations).
- Weight class sets the main trade-off: a Heavy middle hits harder but attacks slower; Light legs move and dodge faster but defend less.
- Your Top's weight class picks your special move: Blink Strike, Shock Pulse or Fortify.
- Current prototype: best-of-3 matches against a CPU rival (Easy / Normal / Hard).

## Play

Open `index.html` in a browser. No install or build step; Three.js loads from a CDN.

## Controls

| Action | Keyboard / mouse |
| --- | --- |
| Move | WASD or arrow keys |
| Light attack | J or left click |
| Heavy attack | K or right click |
| Block (hold) | Shift or L |
| Dodge | Space |
| Special | E (when energy is full) |
| Pause | Esc |

Phones get an on-screen joystick and buttons.
